# Light SEO Suite — Compact SEO Micro-Tools

A curated directory of lightweight, browser-based utilities for organic search research and competitor analysis.

🌐 **Official Hub & Directory**: [Light SEO Suite (Online App)](https://seo-tools-index.pages.dev)

## 🛠 Included Chrome Extensions

### 1. [Competitor Keyword Finder](https://chromewebstore.google.com/detail/competitor-keyword-finder/mmcajkhbkkhmcbaabeajefkdaciohodc)
Analyze competitor domains directly in your browser:
- Extract high-traffic organic search keywords.
- Automated 0-100 Blue Ocean opportunity scoring.
- Instant CSV export across 9 Google search markets.
- **Install**: [Chrome Web Store Link](https://chromewebstore.google.com/detail/competitor-keyword-finder/mmcajkhbkkhmcbaabeajefkdaciohodc)

### 2. [Compare 2 Websites SEO](https://chromewebstore.google.com/detail/compare-2-websites-seo-co/mfoehhkaioagppbbbknhehglkeidncco)
Side-by-side SEO comparison tool for competitor benchmarking:
- On-page DOM, word count, and heading hierarchy diffs.
- Head-to-head Google search rankings.
- Organic keyword gap identification.
- **Install**: [Chrome Web Store Link](https://chromewebstore.google.com/detail/compare-2-websites-seo-co/mfoehhkaioagppbbbknhehglkeidncco)
