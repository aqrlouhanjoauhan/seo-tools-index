Privacy Policy

Last Updated: October 2026

01. Overview & Core Philosophy

SEO360 ("we", "our", or "the extension") provides visual developer tooling and API inspection utilities for DataForSEO. Our architecture is built upon a fundamental privacy principle: Bring Your Own Key (BYOK) and Zero Centralized Data Collection.

We do not operate backend user databases, user tracking systems, or intermediate proxy servers. All software operations are executed locally within your client browser environment.

02. Information We Do NOT Collect

In accordance with the Google Chrome Web Store Developer Program Policies, we explicitly declare that SEO360 does not collect, transmit, or store any of the following:

  • Personally Identifiable Information (PII): Names, email addresses, physical locations, phone numbers, or age.
  • Authentication Credentials on Centralized Servers: We never receive or store your DataForSEO API keys or passwords on any external server.
  • Browsing Activity & Web Content: We do not monitor, intercept, read, or track your browsing history, visited web pages, or clipboard contents.
  • Analytics & Behavioral Tracking: No third-party analytics trackers, telemetry trackers, or advertising SDKs are packaged within this software.

03. Browser Permissions & Technical Justifications

SEO360 requests minimal browser permissions strictly necessary for its advertised functionality:

  • storage: Used solely to persist your user-configured DataForSEO API Login and Password locally in your browser's private sandbox (via chrome.storage.local). This data never leaves your device.
  • Host Permissions (api.dataforseo.com): Used exclusively to send direct client-side HTTPS queries directly to official DataForSEO endpoints using your supplied credentials.
  • Host Permissions (seo360.pages.dev): Used solely to fetch static JSON API parameter schemas and configuration updates. No user data is sent during these requests.

04. Network Communications & Data Transmission

All API queries triggered within the extension communicate directly between your browser client and the official DataForSEO API gateway (https://api.dataforseo.com/v3/) over secure TLS/HTTPS connections. Your requests, queries, and analytical outputs are neither routed through nor accessible to SEO360 developers.

05. Data Sharing & Third Parties

We do not sell, rent, license, trade, or transfer any user data to third parties. We do not partner with data brokers, ad networks, or data intelligence aggregators.
